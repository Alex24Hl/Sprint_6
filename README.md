# Sprint_6 - "Page Object"

## Структура проекта

1. **tests**:

    Папка содержащая ui-тесты на следующую функциональность:
   - **tests_order_scooter.py** - тесты на заказ самоката 
   - **test_questions.py** - тесты на проверку вопросов в выпадающем списои в разделе «Вопросы о важном»

2. **pages**:

    Папка содержащая страницы:
   - **base_page.py** - страница, где находятся базовые методы для работы с объектами
   - **main_page.py** - страница, где находятся методы для взаимодействия с элементами на главной странице
   - **rental_page.py** - страница, где находятся методы для взаимодействия с элементами на странице заказа самоката
   - **status_page.py** - страница, где находятся методы для взаимодействия с элементами на странице статуса
   - **yandex_page.py** - страница, где находится метод для взаимодействия с элементами на странице "Яндекс.Дзен"

3. **locators**:

    Папка содержащая локаторы:
   - **main_locators.py** - страница, где лежат локаторы, которые используются на главной странице
   - **rental_locators.py** - страница, где лежат локаторы, которые используются на странице заказа самоката
   - **status_locators.py** - страница, где лежат локаторы, которые используются на странице статуса
   - **yandex_locators.py** - страница, где лежат локаторы, которые используются на странице "Яндекс.Дзен"

4. **data.py**:  
Класс с данными для параметризации

5. **conftest.py**:  
Содержит фикстуру `driver` для инициализации драйвера

6. **allure_result**:  
Модуль, где находятся результаты выполнения тестов

7. **urls.py**:
Файл, где лежит ссылка на страницу "Яндекс. Самокат"

8. **requirements.txt**:
Список внешних зависимостей
